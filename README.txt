# 🇩🇪 Bremen RP VC – Regelwerk

Diese Version ist für das Hosting als normale Website vorbereitet. Discord-Webhooks wurden entfernt.

## Lokal starten
1. Node.js 18+ installieren.
2. In diesem Ordner ein Terminal öffnen.
3. `npm start` oder `node server.js` ausführen.
4. `http://localhost:3000` öffnen.

## Render
- Build Command: `npm install`
- Start Command: `npm start`
- Die Website verwendet automatisch den von Render gesetzten `PORT`.

## Fehlermeldungen
Das Formular sendet nichts mehr automatisch an Discord. Mit „Meldung kopieren“ wird die Fehlermeldung in die Zwischenablage kopiert, damit sie manuell weitergeleitet werden kann.
